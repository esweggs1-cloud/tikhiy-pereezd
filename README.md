# Тихий переезд · Городские истории 4.0

Уютная одиночная 3D-игра о доставках, переездах и маленьких городских открытиях. Обновление предоставленного Adventure-проекта без обязательных CDN, сборщика и стороннего игрового движка.

## Запуск

Распакуйте архив целиком и откройте `index.html`. Все JS-файлы и папка `vendor` должны оставаться рядом. Для 3D нужен WebGL. На слабом устройстве выберите «Пауза → Графика → Лёгкая».

Для локального HTTP-сервера из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Игра также работает через `file://`; поведение локального хранилища для файлов зависит от браузера.

## Игровой цикл

Диспетчерская → подходящий заказ → получение у золотого маркера → доставка → оплата и репутация. Мятные точки строятся по проходимой карте, с обходом зданий и переходами через мосты. Автопилот помогает добраться, но передать груз нужно самостоятельно. Заказ мастера и экомаршрут содержат три остановки; оплата поступает после последней.

Срочный бонус зависит от активного игрового времени. Меню, сворачивание и закрытая игра не расходуют оставшееся время. Опоздание не уменьшает основную оплату. Серия прерывается при подтверждённой отмене заказа.

Заезды доступны в разделе «Открытия». Сначала нужно приехать к старту. Автопилот и смена транспорта во время заезда недоступны. Первая завершённая попытка даёт награду, следующие улучшают личный рекорд.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение в направлении экрана |
| E / пробел | Взаимодействие у цели |
| Shift | Ускорение |
| N | Автопилот |
| Q / R | Поворот камеры |
| Колёсико | Масштаб |
| J / G / M | Заказы / гараж / карта |
| P / Esc | Пауза; Esc закрывает открытое окно |

На телефоне доступны джойстик, действие, ускорение, камера и все разделы. Задание можно свернуть кнопкой в верхнем правом углу карточки.

## Telegram и приглашения

1. Разместите **все игровые файлы** на HTTPS-хостинге.
2. Укажите публичный адрес в настройках Mini App вашего бота через BotFather.
3. При необходимости задайте `publicUrl` в `config.js`: адрес игры или `https://t.me/имя_бота/имя_приложения`.
4. Откройте «Друзья» и проверьте приглашение. Игрок также может указать публичную ссылку в этом окне.

Telegram SDK подключается асинхронно только при признаках запуска Mini App. Обычный браузер и локальный запуск не ждут Telegram. Поддерживаются расширение окна, кнопка «Назад» и необязательный тактильный отклик. SDK проверяется перед вызовами.

Никакие сообщения не отправляются автоматически. Кнопка приглашения открывает стандартный диалог обмена, а без него копирует ссылку. QR формируется локально. Telegram init data, query-параметры и hash не попадают в приглашение.

**Это одиночная версия.** Список онлайн-друзей, общий рейтинг, аккаунты и одновременная игра требуют отдельного сервера. Рекорды, достижения и деньги в этой сборке хранятся локально; они не предназначены для защищённой соревновательной экономики.

Документация Telegram: https://core.telegram.org/bots/webapps

## Прогресс

Ключ текущего сохранения: `quiet-movers-v4`, резервный: `quiet-movers-v4-backup`. При запуске последовательно проверяются v4, резервная копия и версии v3/v2/v1. Поля нормализуются, неизвестные предметы отбрасываются, некорректный заказ отменяется, позиция внутри препятствия переносится на свободное место. Предыдущие ключи не удаляются.

При недоступном хранилище появляется предупреждение. Экспорт и импорт JSON доступны в паузе. Перед импортом показано подтверждение с количеством доставок и балансом. Большие и некорректные файлы отклоняются. Старое сохранение переносится автоматически только при сохранении того же browser origin; на другой адрес или устройство используйте экспорт/импорт.

## Структура

- `data.js` — районы, адреса, транспорт, грузы, истории и награды.
- `core.js` — валидация сохранений, экономика, генерация заказов и поиск пути.
- `engine.js` — WebGL, геометрия города, тени, вода, транспорт и освещение.
- `game.js` — игровой цикл, интерфейс, управление, задания и прогресс.
- `telegram.js` — необязательная интеграция Mini App.
- `config.js` — публичная ссылка для приглашений.
- `style.css`, `index.html`, `icon.svg` — интерфейс.
- `vendor/qrcode.min.js` — QRCode.js, MIT; лицензия сохранена рядом.
- `tests/core.test.cjs` — тесты правил и навигации на стандартном Node.js.

Запуск тестов без установки зависимостей:

```sh
node tests/core.test.cjs
```

`window.gameDiagnostics()` и `window.gameWorldAudit()` возвращают копии диагностических данных для поддержки. Они не дают доступа к изменению состояния игры.
